### Software Configuration Management (SCM) best practices
* focus on maintaining consistency, traceability, and control throughout the software development lifecycle.
* This includes using version control systems (like git) to manage code changes, establishing clear branching and merging strategies, and maintaining a reliable build and release process.
* It also involves tracking all configuration items (such as code, documentation, and dependencies), enforcing change control procedures, and ensuring proper documentation for every modification.
